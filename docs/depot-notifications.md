# 차고지 출발 알림 상태 연동

알림 발송 후 active=false로 변경하는 책임은 백엔드에 있습니다. 프론트는 FCM 수신 시 상태 변경 API를 호출하지 않습니다.

## 상태 조회

- 차고지 알림 화면을 열면 `GET /api/notifications/depot/my`를 캐시 대신 서버에서 조회합니다.
- 앱 사용 중 FCM 수신, 알림 클릭, 앱이 다시 활성화되었을 때 알림 갱신 이벤트가 발생합니다. 열려 있는 알림 화면은 목록을 다시 조회합니다.
- 백그라운드 수신은 수신 시각과 messageId만 저장합니다. 앱 복귀 또는 화면 진입 시 목록을 조회합니다.
- 서버 목록의 active 값을 enabled로 변환해 버튼 상태를 표시합니다. active=false는 `알림 해제됨`, true는 `알림 설정됨`입니다.
- FCM data의 user_bus_id로 상태를 추측하거나 서버 상태를 변경하지 않습니다. 목록 응답이 상태 기준입니다.
- 알림 클릭 시 홈 화면으로 이동합니다.

## 수동 토글

사용자가 차고지 알림 설정 버튼을 누르면 `PATCH /api/notifications/depot/{userBusId}/status`에 `{ "active": true/false }`를 보냅니다. 요청 성공 후 해당 화면/캐시 상태를 갱신합니다. 실패하면 기존 상태를 유지하며 오류를 표시합니다.

## 확인 방법

1. 서버가 발송 후 active=false로 변경한 뒤 FCM을 보내면, 열려 있는 차고지 목록에서 해당 버튼이 해제 상태로 갱신되는지 확인합니다.
2. FCM 수신만으로 PATCH가 발생하지 않는지 확인합니다.
3. 백그라운드에서 수신 후 앱 복귀 또는 차고지 화면 진입 시 최신 서버 상태를 조회하는지 확인합니다.
4. 사용자가 버튼을 누를 때만 PATCH가 발생하고, 성공 후 설정/해제 상태가 바뀌는지 확인합니다.
